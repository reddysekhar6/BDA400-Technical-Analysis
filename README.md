## Running the work
1. Install R and RStudio.
2. Open the relevant assignment folder in RStudio.
3. Run the `.R` files using the instructions in the corresponding report/README.
4. Assignment 2 requires the `quantmod` package. Assignment 4 requires `dplyr`. Assignment 5 uses base R/core functions for the indicator implementations, as required by the assignment.
5. For Assignment 5, run `test_all_indicators.R` after keeping all indicator `.R` files in the same folder.
