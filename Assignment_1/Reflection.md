# Reflection Questions — Assignment 1

## 1. How did AI support the documentation process?
AI support was useful for organizing the documentation into recognizable sections such as overview, installation, usage, inputs, outputs, verification, and disclosure. The important human contribution was checking that the structure remained aligned with the assignment requirements rather than accepting a generic README structure.

## 2. What did you learn from validating the Markdown?
I learned that readable Markdown is not only about having correct headings. Code fences, lists, file paths, section order, and consistent terminology also affect how useful a README is. Previewing the document is therefore an important quality-control step.

## 3. What are the strengths and limitations of AI-assisted documentation?
AI can quickly suggest structures and identify formatting problems, but it does not know the exact project context unless that context is supplied. It can also produce sections that sound professional but are unnecessary or unsupported. Human review is therefore necessary before publishing the documentation.
